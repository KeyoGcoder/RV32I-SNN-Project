\# RV32I Processor Development Rules



This repository implements a synthesizable RV32I RISC-V processor in Verilog for Xilinx Vivado.



Rules:



\- Modify ONLY the requested files.

\- Never modify previously verified modules.

\- Every RTL module must have a matching self-checking testbench.

\- All code must be synthesizable in Vivado.

\- Use Verilog-2001 only.

\- Avoid latches.

\- Use nonblocking assignments for sequential logic.

\- Explain all important logic with comments.

\- Do not change interfaces without permission.

\- Follow the RV32I ISA specification.
